# Credential

The `Credential` vertical issues, accepts, and deletes on-ledger [credentials](https://xrpl.org/docs/concepts/decentralized-storage/credentials).

| Method | Description |
| --- | --- |
| [issue](issue.md) | Issue a credential to a destination account. |
| [accept](accept.md) | Accept a credential issued to the calling account. |
| [delete](delete.md) | Delete a credential, as either its issuer or its holder. |
| [retrieve](retrieve.md) | Read a single credential. |
| [list](list.md) | List the credentials an account holds or issued. |
