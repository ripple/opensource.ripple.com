# XRP

The `XRP` vertical handles native XRP value transfers and places DEX orders with XRP as the base asset.

| Method | Description |
| --- | --- |
| [transfer](transfer.md) | Send native XRP from one account to another. |
| [buyOffer](buyOffer.md) | Place a DEX order to acquire XRP. |
| [sellOffer](sellOffer.md) | Place a DEX order to sell XRP. |
| [cancelOffer](cancelOffer.md) | Cancel a standing offer placed by the acting account. |
